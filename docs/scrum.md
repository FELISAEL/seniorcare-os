# Plan de trabajo Scrum

## Roles sugeridos

- Product Owner: representa las necesidades de residentes y cuidadores.
- Scrum Master: facilita el proceso y elimina bloqueos.
- Equipo de desarrollo: diseña, implementa, prueba y documenta.

## Backlog inicial

| Prioridad | Historia de usuario |
| --- | --- |
| Alta | Como residente, quiero ver mis medicamentos en botones grandes |
| Alta | Como residente, quiero solicitar ayuda sin navegar por menús |
| Alta | Como residente, quiero activar una emergencia con claridad |
| Alta | Como cuidador, quiero recibir y atender alertas |
| Alta | Como administrador, quiero gestionar residentes y medicamentos |
| Media | Como familiar, quiero iniciar una videollamada sencilla |
| Media | Como administrador, quiero consultar métricas diarias |
| Media | Como operador, quiero monitorear el estado de los servicios |

## Sprints

1. Infraestructura, autenticación y residentes.
2. Medicamentos, horarios y confirmaciones.
3. Asistencia, SOS y videollamadas.
4. Portal unificado, paneles por rol y ETL.
5. Aplicación móvil, modo kiosco y Kubernetes.
6. Pruebas, documentación y presentación.
