# Alcance de la primera versión

## Incluido

1. Inicio de sesión con roles.
2. Perfil demostrativo de una persona adulta mayor.
3. Consulta de medicamentos programados para el día.
4. Confirmación de medicamento tomado.
5. Solicitud de asistencia.
6. Activación de una alerta SOS con confirmación.
7. Creación de una videollamada simplificada.
8. Panel de alertas para cuidador y administrador.
9. Métricas diarias generadas mediante ETL.
10. Monitoreo básico de servicios.
11. Ejecución local con Docker Compose.
12. Manifiestos de Kubernetes.
13. Configuración de Linux en modo kiosco.

## Fuera del MVP

- Diagnóstico médico.
- Prescripción automática de medicamentos.
- Comunicación directa con servicios públicos de emergencia.
- Expediente clínico completo.
- Certificación como dispositivo médico.

El botón SOS del prototipo genera una alerta dentro de SeniorCare. No sustituye
un sistema certificado de atención de emergencias.
